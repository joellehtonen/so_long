# SO LONG
---
### What is this?
- So Long is the first game project I made in Hive. A simple, top down, 2D game where the players must collect collectibles and reach the exit.
---
### What I learned?
- This is the first graphical project, so I had learn how to use our graphical library, MLX42.
- For the get-go, I wanted the player movement be smooth, and not tile-based as many of my peers did, so I had figure out a method to make it work in a world that is fundamentally tile-based. 
- Animation also took surprisingly long, but honestly I am pretty happy with how it turned out. It's one of things I could spend endlessly tinkering.
- The map parsing and validating was also an important part of the project.
- How the enemy moves and behaves, how to make it threatening enough but also something the player can outsmart, all of that took a bit of thinking, and I am happy with the results. Coding it wasn't too hard. 
---
### What I would do differently?
- Honestly, not much. It turned out pretty great. Would love to expand it even further, but the subject set many restrictions around it.
